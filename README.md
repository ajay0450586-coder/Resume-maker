# Resume Maker App

A modern React-based resume builder where users can fill their personal and professional details through an interactive form, preview the resume with smooth animations, and download it as a PDF.

## Features
- Interactive form with real-time preview
- Framer Motion animations for smooth UX
- Responsive design with clean CSS
- PDF download functionality
- Professional resume templates
- Sectioned layout (Personal Info, Experience, Education, Skills, etc.)

## Tech Stack
- React (JavaScript)
- CSS (Custom styling)
- Framer Motion (Animations)
- html2canvas + jsPDF (PDF generation)

## Quick Start
1. `cd resume-maker-app`
2. `npm install`
3. `npm run dev`
4. Open http://localhost:5173
